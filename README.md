A 2D fighting game with wayang kulit shadow puppets. Arjuna, the swift archer of Hastina, duels Rahwana, the heavy-hitting king of Alengka, on a lamp-lit kelir screen. Punch, kick, block and jump, fill the special meter, then unleash Panah Pasupati or Api Alengka. Best of three rounds, 60 seconds a round, first to two round wins takes the match.

## Controls

- **A / D** — move, **W** — jump, **S** — block
- **J** — punch, **K** — kick, **L** — special move (only when the meter is full)
- **Enter** — start the match, **R** — fight again after the results screen

Landing hits and taking damage fill the special meter. The AI opponent gets faster and more aggressive every round. All art is drawn on canvas and all sound is synthesized with WebAudio — no image, font or audio files, and no network requests.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome.
